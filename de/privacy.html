Datenschutz

Kurz gesagt: Dateien, die Sie mit Open Online öffnen, werden in Ihrem Browser verarbeitet und nicht hochgeladen. Es gibt keine Analyse-Tools, keine Werbung und kein Benutzerkonto.

1. Dateien, die Sie öffnen

Wenn Sie eine Datei mit Open Online öffnen, liest Ihr Browser sie von Ihrem Gerät, und der Viewer läuft im selben Browser-Tab. Open Online hat keinen Upload-Endpunkt und keine serverseitige Verarbeitung: Die Datei wird weder an uns noch an Dritte gesendet.

Geöffnete Dateien liegen nur im Arbeitsspeicher des Tabs. Sie werden nicht in Cookies, localStorage, IndexedDB oder den Offline-Cache geschrieben und sind weg, sobald Sie den Tab schließen oder neu laden. Bearbeitete Kopien werden nur gespeichert, wenn Sie „Kopie speichern“ wählen; dann lädt Ihr Browser sie auf Ihr Gerät herunter.

Die Funktion „Überblick“ wird auf Ihrem Gerät mit einfachen Zählregeln berechnet. Es werden keine Dokumentinhalte an einen KI-Dienst oder einen anderen externen Dienst gesendet.

Manche Dateien enthalten Verweise auf Inhalte im Internet, etwa externe Bilder in einer HTML- oder Markdown-Datei. Die Content Security Policy der Website blockiert solche Anfragen, sodass beim Öffnen einer Datei keine anderen Server kontaktiert werden.

2. Besuch der Website

Die Website besteht aus statischen Dateien, die auf GitHub Pages gehostet werden, einem Dienst der GitHub, Inc. (USA). Beim Laden einer Seite sendet Ihr Browser eine Anfrage an die Server von GitHub. Wie jeder Webserver verarbeitet GitHub dabei technische Daten, um die Seite auszuliefern und den Dienst abzusichern – insbesondere Ihre IP-Adresse, die angefragte Adresse, Datum und Uhrzeit sowie den User-Agent Ihres Browsers. GitHub kann diese Daten in Server-Logs speichern. Wir haben keinen Zugriff auf diese Logs und nutzen sie nicht.

Diese Verarbeitung ist für die Auslieferung der Website erforderlich und beruht auf unserem berechtigten Interesse an einer funktionierenden und sicheren Website (Art. 6 Abs. 1 lit. f DSGVO). GitHub kann Daten in den USA verarbeiten. Weitere Informationen finden Sie im GitHub General Privacy Statement (öffnet in neuem Tab).

3. Keine Cookies, keine Analyse, keine Werbung

Open Online setzt keine Cookies, nutzt keine Analyse- oder Tracking-Tools, zeigt keine Werbung und hat keine Benutzerkonten. Schriften und der gesamte Programmcode werden von der Website selbst ausgeliefert; es werden keine Content-Delivery-Netzwerke oder Drittdienste kontaktiert.

4. Offline-Nutzung

Damit die Website offline funktioniert und schneller lädt, registriert sie einen Service Worker, der die eigenen Dateien der Anwendung (Code, Stile, Symbole) im Cache Ihres Browsers speichert. Dieser Cache enthält nie Dateien, die Sie öffnen. Sie können ihn jederzeit entfernen, indem Sie die Websitedaten in den Browsereinstellungen löschen.

5. Links zu aintob.com und anderen Websites

Open Online verlinkt zum Umwandeln von Dateien auf aintob.com (öffnet in neuem Tab). aintob.com ist ein eigenständiger Dienst mit eigener Datenschutzerklärung, dessen Praxis von der hier beschriebenen abweichen kann. An aintob.com wird nichts übermittelt, solange Sie dem Link nicht folgen und die Website nutzen.

6. Kontakt und Ihre Rechte

Wer für diese Website verantwortlich ist, steht im Impressum. Sie erreichen uns unter open-online@dittes.info.

Nach der DSGVO haben Sie das Recht auf Auskunft, Berichtigung, Löschung und Einschränkung der Verarbeitung Ihrer personenbezogenen Daten, das Recht auf Datenübertragbarkeit und das Recht, einer auf berechtigten Interessen beruhenden Verarbeitung zu widersprechen. Außerdem können Sie sich bei einer Datenschutz-Aufsichtsbehörde beschweren. Da Open Online selbst keine personenbezogenen Daten erhebt, sind Anfragen zu Hosting-Logs gegebenenfalls an GitHub zu richten.
