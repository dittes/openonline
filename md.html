About Markdown files

Markdown is a lightweight way to write formatted text using plain characters: # for headings, * for lists, backticks for code. README files, documentation and many note apps use it.

Open Online renders GitHub-flavoured Markdown, including tables and task lists, next to an editor for the source.

What you can do here

  • Rendered preview with headings, lists, tables and code blocks
  • Side-by-side source and preview while you edit
  • Save the edited Markdown
  • Search the source

Limitations

  • Images that point to web addresses are not loaded, so nothing is fetched from other servers.

Privacy

The file is read by your browser and stays on your device. Open Online has no server that could receive it, and nothing is stored once you close the tab. Privacy policy

Common questions

Why don’t images show up?

Images that point to web addresses are blocked on purpose, so opening a file never contacts other servers.

Is HTML inside Markdown allowed?

Basic HTML is rendered, but scripts, forms and embedded frames are removed.
