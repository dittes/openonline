About Python files

Python scripts (.py) are plain text files with Python code.

Open Online shows them with syntax highlighting and line numbers. The code is never run.

What you can do here

  • Line numbers and syntax highlighting
  • Search and replace
  • Toggle word wrap
  • Edit the text and save a copy
  • See encoding, line endings, line and word counts

Limitations

  • Very large files (over 50 MB) open read-only to keep the browser responsive.

Privacy

The file is read by your browser and stays on your device. Open Online has no server that could receive it, and nothing is stored once you close the tab. Privacy policy

Common questions

Can I open Jupyter notebooks?

Notebooks (.ipynb) are JSON files and open in the JSON viewer, where you can read the cells and outputs as data.
