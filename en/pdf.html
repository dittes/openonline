About PDF files

PDF is the standard format for documents that should look the same everywhere: contracts, invoices, papers, manuals, boarding passes. A PDF stores text, fonts, images and vector graphics with a fixed layout.

Open Online uses PDF.js, the same engine Firefox uses to show PDFs, running entirely in your browser tab.

What you can do here

  • Scroll through all pages, with thumbnails in the sidebar
  • Zoom, fit to width or page, and rotate the view
  • Search the text and jump between matches
  • Select and copy text
  • Use the PDF’s own table of contents, if it has one
  • Check title, author, PDF version, page size and other properties
  • Open password-protected PDFs if you know the password

Limitations

  • Form fields are shown but can’t be filled in and saved.
  • Scanned PDFs without a text layer can be viewed but not searched.

Privacy

The file is read by your browser and stays on your device. Open Online has no server that could receive it, and nothing is stored once you close the tab. Privacy policy

Common questions

Can I open a password-protected PDF?

Yes, if you know the password. You’ll be asked for it when the file opens. The password is used locally to decrypt the file and isn’t sent anywhere.

Why can’t I search my PDF?

Scanned documents are often just images of pages without a text layer. They display fine, but there is no text to search or copy. An OCR tool can add a text layer.

Can I edit the PDF here?

No. Open Online is for viewing and inspecting. For changes, use a PDF editor; for converting a PDF into another format, aintob.com has a PDF converter.
